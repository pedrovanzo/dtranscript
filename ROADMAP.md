# Roadmap

Planned refinements for dtranscript.

- [ ] **Sharpen the UI**: review UI responsiveness and improve it with the appropriate tools.
- [ ] **Transcripts page**: browse past transcribed files, grouped into useful categories (study, entertainment, etc.).
- [ ] **React shop app integration**: include dtranscript in the React shop app and its history.
- [ ] **Reference for the dasdk agents project**: dtranscript is a good example of an agent for dasdk agents (single-purpose pipeline, prompt templates in `prompts/`, LLM access through the `claude` CLI). Mention and link it there.
- [ ] **Memory Palace feeder agent**: a follow-up agent that picks up dtranscript outputs, prioritizing those with teachable moments ("What the video teaches" section), and transforms them into data that feeds the Memory Palace. Memory Palace is a separate project, not built yet, holding consolidated memories of learnings over time.
